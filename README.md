# K-Delivery Sim

Three.js + TypeScript + Vite 기반의 **한국형 1인칭 오토바이 배달 시뮬레이션** 웹 게임입니다.  
별도 설치 없이 브라우저에서 바로 최대 3건 동시 묶음 배달(다건 배차), 3칸 배달통 슬롯 관리, A* 도로망 내비게이션 경로 유도, 라이딩 턴바이턴 거치대 미니맵, 야외 픽업대 POS 번호 입력, 공동현관 PIN·엘리베이터 이동, 문 앞 배달 인증 사진 촬영까지 전 과정을 체험할 수 있습니다.

### 🎮 지금 바로 플레이하기
👉 **https://typoscript.github.io/k-delivery-sim/**

## 주요 기능

- **실제 수원시 팔달구 인계동 (수원시청역 일대) OpenStreetMap 실측 3D 도시 맵**
  - 실제 OpenStreetMap 지리 데이터를 정적 번들([suwonIngyeData.ts](./src/data/suwonIngyeData.ts), © OpenStreetMap contributors ODbL)로 변환해 **효원로 · 권광로 · 경수대로 · 권선로 · 나혜석거리** 등 **218개 실제 도로 세그먼트(175개 연결 교차점, 24개 신호등 교차로)**를 1:1 축척(약 800m × 800m)으로 구현
  - **322개 실제 건물 폴리곤 3D 압출:** `수원시청역 (수인분당선)`, `효원공원`, `롯데시네마`, `뉴코아아울렛 동수원점`, `CGV 동수원`, `Homeplus`, `한화꿈에그린 101~103동`, `한라비발디파크`, `수원프라자 오피스텔`, `삼성화재빌딩`, `국민연금 수원사옥` 등 실제 위치·외곽선·층수를 반영
  - **인계동 실제 매장 10곳 & 주거지 12곳:** `유치회관 (해장국)`, `교동짬뽕 인계점`, `스타벅스 수원시청점`, `버거킹 수원시청역점`, `롯데리아 수원시청점`, `제라진돈카츠 인계점`, `홍대쌀국수 동수원점`, `쿠우쿠우 수원시청점`, `인계동 황금통닭·포차`, `맥도날드 인계DT점` 및 인계동 아파트·오피스텔·구축 빌라 4곳, 수원시청역 버스정류장 8곳, `경기남부경찰청 POLICE 112` 순찰차 반영
  - **일반 OSM 도로 그래프 엔진 전환:** A* 경로 탐색기([RoadNavigator.ts](./src/world/RoadNavigator.ts)), 교통 AI([TrafficSystem.ts](./src/world/TrafficSystem.ts)), 보행자 그래프([PedestrianGraph.ts](./src/world/PedestrianGraph.ts)), 단속·공사·경쟁 라이더([RoadHazardManager.ts](./src/world/RoadHazardManager.ts)), 스마트폰 GPS 지도([PhoneMap.ts](./src/ui/PhoneMap.ts)) 모두 임의 각도의 실제 수원 OSM 도로망에서 실시간 동작
- **한국어 음성 내비게이션 (`Web Speech API`), 헬멧 바이저 빗방울 닦기(`G`), 설정창(`O`) & 첫 출근 1분 가이드**
  - **한국어 음성 내비게이션 (`ko-KR` TTS):** 브라우저 내장 Web Speech API로 주행 중 회전 안내(*"약 40미터 앞에서 우회전입니다"*), **80m 전방 과속·신호 단속 경보**(*"전방 80미터 앞, 시속 50킬로미터 신호 과속 단속 구간입니다"*), 조리 완료·신규 콜·고객 메시지 도착 음성 안내 제공 (에셋 0KB · 설정창에서 ON/OFF)
  - **우천 시 1인칭 헬멧 바이저 빗방울 & 장갑 손 닦기 (`G`):** 비 올 때 시야에 굴절 빗방울이 맺혀 흘러내리며, **`G` 키**를 누르면 1인칭 라이더 장갑 손이 스퀴지 효과음과 함께 화면을 쓱 가로질러 빗방울을 닦아냄 (실내 복도 진입 시 즉시 제거)
  - **도로 1차선 공사구간(라바콘) 3곳 & 경쟁 AI 배달 오토바이 4대:** 간선도로 3곳에 주황·흰 반사 띠 라바콘·점멸 경광등·`"🚧 도로 공사 중 · 1차선 통제"` 바리케이드 배치(실제 차선 우회 필요), 민트/주황/파랑/노랑 배달통을 단 경쟁 AI 배달 스쿠터 4대가 신호등을 지키며 도시 곳곳을 순환 주행 (GPS 지도 `🚧` 및 라이더 점 표시)
  - **첫 출근 1분 인터랙티브 가이드 & 환경 설정 모달 (`⚙️ 설정` / `O`):** 첫 배달 4단계(콜 수락 → 오토바이 탑승 → 픽업/적재 → 배달 완료)를 실시간 체크리스트로 안내하고, 설정창에서 마스터 음량·한국어 음성안내·마우스 시선 감도·그래픽 품질(`높음/보통/낮음`)을 `localStorage`에 자동 저장
- **음식 종류별 물리(국물·음료 쏟음), 보온·보냉 온도 관리 & 도로 과속방지턱 14곳**
  - 모든 메뉴가 **🍲 국물/음료류(마라탕·국밥·육개장·아메리카노·스무디 등)**, **🍕 수평/흔들림 주의(피자·케이크)**, **🔥 따끈 보온 / 🧊 보냉** 특성으로 분류되어 스마트폰 콜 카드·배달통 슬롯에 표시됨
  - **국물·음료 실시간 흔들림 물리:** 전도하지 않더라도 국물/음료/피자 적재 중 **과도한 코너링 기울기(`> 25°`)** 또는 **급가속·급브레이크** 시 출렁임 효과음과 함께 음식 상태가 실시간 감점
  - **보온·보냉 온도 게이지:** 픽업 완료 시점부터 음식 온도(`100%`)가 서서히 하락하며, **아이스 음료/디저트(`🧊 보냉`)는 뜨거운 음식보다 약 1.45배 빠르게 온도 손실** → 묶음 배달 시 동선 우선순위 전략 유도 (배달통 적재 시 보온/보냉백 효과로 감속, 온도 `80%↑` 유지 시 **`+₩300` 온도 보너스**, `50%↓` 시 배달팁 감액)
  - **한국형 노랑/검정 과속방지턱 14곳:** 주거단지·상가 진입 도로에 반원형 과속방지턱과 경고 표지판 배치 — **22km/h 초과 고속 통과 시** 서스펜션 바운스·충격음과 함께 배달통 음식 파손 발생 (국물/음료는 최대 `-16%`)
- **한국형 배달지 다양화(엘리베이터 없는 구축 빌라 계단) & 배달 중 고객 돌발 채팅 이벤트**
  - **엘리베이터 없는 구축 빌라 4곳(`그린빌라 A/B/C동`, `소나무 빌라`):** 2~4층 호수로 배정되며 공동현관 개방 후 엘리베이터 대신 **테라조 계단실과 철제 난간을 1인칭으로 직접 걸어 올라가는 계단 배달** 진행 (계단 등반 시 체력/스태미나 소모·발소리·층수 HUD 표시, 배달 완료 시 **`🪜 구축 빌라 계단 수고비 +₩500`** 자동 지급)
  - **배달 중 실시간 고객 채팅 이벤트:** 오토바이로 배달 이동 중 메신저 알림음과 함께 비차단 고객 채팅 팝업 도착 (스마트폰 상단 툴팁·수락 주문 카드에도 실시간 동기화)
    - **👶 아기 수면 요청 변경:** 대면/노크 요청이 실시간으로 **`📸 문 앞 사진`**으로 자동 변경
    - **🏠 호수 오기재 정정:** 잘못 기재된 호수를 같은 층 실제 호수로 즉시 변경 (`CorridorRoom` 팻말·목표 문 자동 반영)
    - **🙏 조심 배달 응원 & 추가 팁 약속:** 음식 상태 `85%` 이상 유지 시 정산에 **`+₩1,000` 약속 팁** 추가 지급
- **배민커넥트 스타일 일일 정산 명세서 & 일일 배달 미션 대시보드**
  - 스마트폰 배달앱 상단에 **`[콜 목록]`**, **`[내비]`**, **`[수익]`** 3단 탭 네비게이션 구성
  - **`[수익]` 탭**에서 오늘의 배달 내역을 영수증 형태로 출력: 기본 배달료 합계, 거리 할증, 우천/기상 할증, 안전 팁·미션 보너스, 신호위반/인도사고 과태료 차감, 음식 파손 페널티 차감, 유류비/수리비, **최종 실수령액(Net Earnings)**
  - **일일 배달 미션 위젯:** `"오늘 3건 배달 완료하기 (현재 X/3)"` 실시간 게이지 바 표시, 3건 달성 시 **`+₩5,000 보너스 지급!`** 축하 팝업·팡파르 재생 및 지갑 잔고 즉시 추가
- **피크타임 매장 조리 지연 대기(Cooking Delay) & 픽업대 트레이 수령**
  - 주문이 몰리는 식당 야외 POS에서 주문번호 입력 시 즉시 나오지 않고 **5~10초 랜덤 조리 대기(`cooking_wait`)** 상태로 진입
  - 상단 HUD 및 거치대/손 3D 스마트폰 화면에 **노란색 조리 대기 카운트다운 게이지**가 표시되며, 대기 중에도 조작이 잠기지 않아 오토바이 탑승·이동·스마트폰 조작이 자유롭게 가능
  - 조리 완료 시 `"음식이 준비되었습니다!"` 딩동 알림음과 함께 야외 픽업대 트레이에 **3D 포장 봉투가 스폰**되며, 다시 `E` 키를 눌러야 왼손에 음식 봉투(`CARRYING_FOOD`)를 쥐게 됨
- **고객 요청사항 3종 분기 & 한국형 아파트 공동현관 PIN 다변화**
  - 모든 콜에 **`PHOTO_DOOR`(📸 문 앞 사진)**, **`KNOCK_DOOR`(✊ 노크 후 문 앞)**, **`MEET_FACE`(🙋 직접 대면 수령)** 요청사항이 부여됨
  - **`PHOTO_DOOR`:** 발매트에 `E`로 내려놓고 카메라 뷰파인더 중앙 60% 화각 내에 **호수 팻말 + 음식 봉투**를 모두 담아 `Space` 촬영 시 배달 완료 승인 (누락/잘림 시 경고 팝업 & 재촬영 유도)
  - **`KNOCK_DOOR`:** 문 앞에서 `E` 입력 시 현관문 노크음("똑똑똑") 재생 + 발매트 자동 배치 → 3초 후 완료
  - **`MEET_FACE`:** 현관문 옆 인터폰 벨(`E`) → "딩동! 누구세요? 배달이요!" 효과음 → 현관문이 부드럽게 **70°**로 열리며 **3D 저폴리곤 고객 NPC**가 손을 내밀어 음식을 수령 후 완료
  - **공동현관 PIN 다변화:** 단순 4자리 외에 `종모양(🔔) + 1234`, `열쇠(🔑) + 5678 + 통화(📞)`, `# + 3920 + *` 등 한국 아파트 출입 패턴을 스마트폰 상단 강조 툴팁과 도어락 특수키 패드로 지원
- **한집배달 vs 알뜰 묶음 배달 선택지 & 20초 카운트다운 콜 카드 + 1인칭 스마트폰 터치 손 조작**
  - `OrderDispatchManager` 상태 머신이 **🚀 한집배달(`SINGLE`: 기본 ₩4,500 + 거리 할증 · 제한시간 300초 · 단건 직행)**과 **🛵 알뜰배달(`ALTTLE_BUNDLE`: 기본 ₩2,800 × 2건 · 제한시간 500초 · 탑박스 2슬롯 분할 순차 배달)** 신규 콜을 자동 배차
  - 배민커넥트 스타일 Web Audio API 비프 알림음·진동 연출과 함께 스마트폰 화면 중앙에 **20초 원형 프로그레스 바 콜 카드** 팝업
  - **터치 전용 조작 & 3D 인월드 바로 터치 + 1인칭 터치 손 연출:** 단축키 자동 콜 수락을 제거하여 실제 스마트폰처럼 **마우스 터치로만 조작**하며, 라이딩 중 3D 핸들바 거치대/손 휴대폰에 마우스를 올리면 1인칭 라이더 장갑 손이 나타나 **화면 확대 없이도 `[👆 바로 터치 수락]` / `[거절]`을 UV 좌표로 직접 눌러 3D 리플·터치음과 함께 즉시 처리** 가능
  - 20초 내 미응답(시간 초과) 또는 거절 시 자동 취소 후 **10초 쿨다운**을 거쳐 신규 콜 재발송
- **무인 과속·신호 단속 카메라(50km/h) · 80m 내비 경보 · 과태료 고지서 팝업 · 한국 경찰 순찰차(`POLICE 112`) & 불법주정차 갑툭튀 (`RoadHazardManager`)**
  - 주요 간선도로 6곳에 **고정식 신호·과속 단속 카메라(제한 50km/h)** 설치(스마트폰 GPS 지도 적색 `50` 마커 표시)
  - **80m 전방 내비 단속 경보:** 카메라 80m 이내 접근 시 스마트폰 화면(3D 거치대 + 확대 앱)에 `"📷 전방 XXm 신호·과속 단속"` 경고 배너와 한국형 내비 안내음(`딩동!`) 재생, 제한속도 초과 주행 중에는 적색 점멸 및 과속 비프음(`삐-삐!`) 송출
  - **경찰청 과태료 고지서 팝업:** 과속(`> 52km/h`) 또는 적색 신호위반 통과 시 스트로브 플래시·셔터 경보음과 함께 우측 상단에 **비차단 경찰청 교통과태료 고지서 카드**(위반 항목·단속 지점·측정 속도·발생 시각·`-₩40,000` 즉시 차감) 슬라이드 출력
  - **한국 경찰 순찰차 (`POLICE 112`) 2대 순찰 AI:** 적/청 교차 LED 경광등을 켜고 간선도로를 순찰(GPS 지도 `🚓` 실시간 표시)하며, 순찰차 반경 22m 내에서 60km/h 초과 과속 시 **경찰 사이렌 + 현장 단속 과태료 고지서(`-₩50,000`)** 발부
  - 상가 도로변 6곳의 **비상등 불법주정차 `K-택배` 탑차·승용차** 접근 시 사각지대에서 **보행자 갑툭튀 돌발 이벤트** 발생 (실내 복도 진입 시 모든 단속·순찰·돌발 요소 자동 오클루전)
- **오토바이 연료 · 셀프 주유소 · 차량 파손 정비 & 일일 종합 정산 대시보드**
  - 주행 시 실시간 연료 소모, **3D 핸들바 계기판 디지털 연료 게이지 & 연료 10% 이하 적색 경고등 점멸 + 경고음**, 연료 고갈 시 가속 불가 전환
  - 메인 대로변 **⛽ K-오일 셀프주유소**에 오토바이를 세우고 도보 `E` 키로 셀프 주유(진행도 바 & Web Audio 결제 완료음 `"결제가 완료되었습니다"`)
  - 슬립 전도 누적 시 **차량 파손 단계(1~3단계)** 적용(사이드미러 틀어짐·흔들림 및 단계당 가속력 `-10%` 저하) → **🔧 번개 오토바이 센터**에서 수리비 결제 후 100% 복구
  - 스마트폰 앱 **`[수익/지출]` 탭** 및 **일일 종합 정산 대시보드 모달**에서 완료 건수, 기본 배달료, 거리/우천 할증, 안전 팁, 유류비, 수리비, 신호위반 과태료, 최종 순수익을 한눈에 확인
- **우천 날씨 쉐이더 & 빗길 노면 슬립(맨홀·횡단보도) 물리 + 우천 할증**
  - `U` 키(또는 상단 날씨 배지 클릭)로 **맑음 / 흐림 / 비(Rain)** 날씨 전환 가능
  - 우천 시 전체 라이팅 톤 다운·짙은 빗안개 적용 및 카메라 주변 로컬 비 파티클(`InstancedMesh` 1 DrawCall)과 Web Audio 프로시저럴 빗소리 재생 — **실내 복도(`y = -500`) 진입 시 비 파티클·빗소리 즉시 중단/음소거**
  - 도로 아스팔트 커스텀 쉐이더로 젖은 노면의 `roughness` 저하 및 웅덩이 반사·물결 하이라이트 구현
  - 36개 교차로의 **금속 맨홀 뚜껑** 및 **횡단보도 흰색 페인트선** 위에서 우천 시 브레이크 또는 급회전하면 접지력(Grip)을 잃고 미끄러져 전도(배달통 음식 파손도 증가 및 배달팁 감액 반영)
  - 우천 모드에서 생성되는 신규 배달 콜에 **`🌧️ 우천 할증 (+₩1,500)`** 라벨 및 정산 보너스 자동 적용
- **묶음 배달(다건 배차) & 배달통 3칸 슬롯 관리**
  - 스마트폰 배달앱에서 **최대 3건 동시 배차** 가능 (`콜 대기` / `수락 목록` / `완료 체크` / `추천 동선` 4개 탭 제공)
  - 오토바이 뒤편 배달통(탑박스)에 **3칸 슬롯(슬롯 1~3)** 도입 및 후면 3구 상태 LED·내부 봉투 시각화
  - 배달통 앞에서 `E` 키를 누르면 슬롯 관리 모달이 열리며, `1`~`3` 키 또는 클릭으로 주문번호(`A-12`, `B-07` 등)와 목적지·호수·PIN·음식 상태를 확인하며 개별 적재/회수 가능 (잘못 꺼낸 음식 재적재 지원)
  - 음식을 손에 든 상태(`CARRYING_FOOD`)에서는 오토바이 탑승/운전이 차단되며, 전도 사고 시 배달통에 적재된 모든 주문의 음식 상태에 파손도가 반영됨
- **스마트폰 전용 A* 도로망 내비게이션 & 3D 거치대 미니맵**
  - 6×6 교차로(36개 노드) 도로망 그래프 기반 **A* 최단 경로 탐색기**와 픽업→배달 선행 조건을 반영한 **묶음 추천 동선 가이드** 자동 계산
  - 3D 도로 위 가상 안내선이나 하늘 기둥 없이 **오직 스마트폰 내비게이션 화면만 보고 주행하는 실감형 배달 방식** 적용
  - 라이딩 중 오토바이 거치대에 휴대폰을 장착(`Tab`)하면 **진행 방향 상단(Heading-Up) 회전 미니맵 + A* 경로선 + 회전 화살표(직진/좌회전/우회전/유턴/도착) + 남은 거리(m)**를 3D 화면에 실시간 표시
- **전체 한국형 배달 워크플로우 (7단계)**
  1. **묶음 콜 수락 (`Tab` → `V`):** 스마트폰 배달앱에서 주문번호(`A-12` 등), 고객 호수(`1402호`), 공동현관 PIN이 포함된 콜을 최대 3건까지 수락
  2. **매장 야외 픽업대 & POS 입력 (`E`):** 매장 앞 야외 픽업대에서 `E`를 눌러 POS 키패드에 주문번호 입력 → 1인칭 왼손에 3D 음식 포장 봉투 장착 (`CARRYING_FOOD`)
  3. **오토바이 배달통 3칸 슬롯 적재 (`E` → `1`~`3`):** 뒤편 배달통에서 `E`로 슬롯 창을 열어 빈 칸에 적재 (`CARGO_LOADED`) → `F`로 탑승해 다음 매장 또는 배달지로 주행
  4. **배달지 도착 & 해당 슬롯 꺼내기 (`F` → `E` → `1`~`3`):** 목적지 도착 후 하차하여 배달통에서 해당 주문번호 슬롯의 음식 꺼내기
  5. **1층 공동현관 비밀번호 & 엘리베이터 (`E`):** 1층 유리문 앞에서 4자리 PIN 입력 시 유리문 개방 → 엘리베이터 탑승 시 2초 검은 페이드아웃 전환
  6. **모듈형 아파트 실내 복도 (`y = -500`) & 렌더링 최적화:** 지하 독립 복도 룸으로 순간이동하며 **외부 도시 맵·내비 라인·트래픽·오토바이 그룹을 `visible = false`로 완전 차단**
  7. **문 앞 내려놓기 & 인증 사진 촬영 (`E` → `Space`):** 목표 호수 발매트 앞에서 `E`로 음식 내려놓기 → 카메라 뷰파인더 → `Space`로 인증샷 촬영 및 정산 → 엘리베이터 복귀 후 다음 묶음 동선 자동 안내
- **항상 1인칭 시점 + 실시간 후방 사이드미러 + 깜빡이**
  - 도보 눈높이 1인칭 이동, 오토바이 핸들바 시점 + 코너 호라이즌 롤
  - 좌/우 핸들바 사이드미러에 실시간 좌우 반전 후방 도로·AI 차량 표시
  - `Q` / `E` / `X` 깜빡이·비상등 (3D 계기판 LED, 바엔드 램프, 틱톡 사운드, 회전 후 자동 해제)
- **3D 1인칭 손 & 오토바이 거치대 스마트폰 + 물리적 소지 판정 (`Tab` / `V`)**
  - 평소에는 주머니 수납 / 도보 중 `Tab`으로 3D 오른손에 들기 / 라이딩 중 `Tab`으로 **3D 손이 주머니에서 꺼내 오토바이 거치대에 장착·분리하는 애니메이션** 재생
  - **물리적 소지 규칙:** 휴대폰을 오토바이 거치대에 꽂아둔 채 하차(`F`)하면 도보 중 앱 확대(`V`), 자동 주문번호/PIN 메모 조회, 엘리베이터 인증 촬영 진입이 차단되며 오토바이 근처에서 `Tab`으로 챙겨야 함
- **확장된 한국형 도시 맵 (25개 블록 · 인도 · 버스정류장 · 시내버스)**
  - 6×6 도로망(36개 교차로, 약 570m × 570m 규모)과 40동 이상의 상가·아파트·오피스텔·병원·백화점·고층 타워 배치 (픽업 매장 9곳, 주거지 배달처 12곳)
  - 보도블록 텍스처, 화강암 연석, 점자블록, 코너 볼라드, 한국형 버스정류장 8곳, 36개 교차로 3색 신호등
  - **저폴리곤 차량 & 선단 12m 레이캐스트 교통 AI (`TrafficSystem`):** 베벨 가공 저폴리곤 세단·**서울 택시(주황/은색, 지붕 캡 점등 & 빈차등)**·시내버스 24대가 플레이어 반경 120m 내 순환 스폰되며, 신호등 RED/YELLOW 정지선 3m 전 감속 정차(`DECELERATING → STOPPED`), 전방 12m 레이캐스트 5m 앞차 추돌 방지, 플레이어 끼어들기 시 급정거 및 1회 Web Audio 경적음 송출 (실내 복도 진입 시 `visible = false` 완전 차단)
  - **인도 웨이포인트 & 횡단보도 신호 연동 보행자 AI + 인도 주행 회피/사고 페널티 (`PedestrianGraph` & `PedestrianManager`):**
    - 25블록 인도 중심선·노란 점자블록 횡단보도 그래프(200노드·80개 횡단보도) 위에서 `WALKING`(1.0~1.3 m/s) → `WAITING_CROSSWALK`(점자블록 대기) → `CROSSING`(교차로 3색 신호등 연동, 점멸 시 1.5배 달리기) FSM 이동, 80m 밖 자동 컬링 및 복도(`y = -500`) 진입 시 틱 일시정지
    - **보행자 근접 경계 반응:** 오토바이가 보행자 전방·측방 **3.5m 이내**로 접근 시 걸음을 멈추고 움츠림·방어 회피 스텝(`STARTLED`) 및 놀람 효과음 재생
    - **보행자 접촉 사고 판정(AABB + BoundingSphere):** **시속 5km/h 이상 주행 중** 보행자와 직접 접촉 시에만 사고로 판정(정차·주차/하차 중 오작동 방지) → 보행자 넘어짐 애니메이션(`FALLEN`), 오토바이 즉시 슬립 전도(배달통 음식 파손 `-55%`), 상단 **`🚨 보행자 접촉 사고 발생!`** 경고 배너 출력, **과태료·합의금 -₩50,000 즉시 차감** 및 **배달 기사 신뢰 평점 -1.0점** 감점 처리

## 조작법

| 키 | 기능 |
| :--- | :--- |
| `F` | 오토바이 탑승 / 하차 / 쓰러진 오토바이 일으켜 탑승 *(음식 든 채 운전 불가)* |
| `E` | *(도보)* 야외 픽업 POS / 배달통 3칸 슬롯 / 주유소 주유 / 정비소 수리 / 공동현관 PIN / 엘리베이터 / 문 앞 내려놓기 · *(라이딩)* 우깜빡이 |
| `1` `2` `3` | *(배달통 슬롯 모달)* 1~3번 슬롯 음식 즉시 적재 / 꺼내기 |
| `Tab` | *(도보)* 주머니 ↔ 3D 손 휴대폰 · *(라이딩)* 주머니 ↔ 3D 오토바이 거치대 (내비 모드) |
| `V` / `3D 폰 클릭` | 휴대폰 확대해서 보기 / 축소 (`Esc` 축소) |
| `Space` | *(카메라 모드)* 배달 인증 사진 촬영 · *(도보)* 점프 · *(라이딩)* 급브레이크 |
| `W` `A` `S` `D` | 도보 이동 / 오토바이 가속·브레이크(저속 후진)·조향 |
| `Shift` | *(도보)* 달리기 |
| `마우스 드래그` / `←` `→` | 1인칭 시선 회전 (`R` 또는 더블클릭으로 정면 복귀) |
| `Q` / `X` | 좌깜빡이 / 비상등 |
| `U` / `G` | 날씨 전환 (`맑음` → `흐림` → `비 / 우천 할증 +₩1,500`) / 헬멧 바이저 빗방울 손으로 닦기 |
| `L` / `N` | 헤드라이트 / 낮·밤 전환 |
| `H` / `M` / `O` | 경적 / 음소거 / 환경 설정 모달 (`⚙️ 설정`) |
| `Backspace` | 위치 초기화 |
