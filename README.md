# K-Delivery Sim

Three.js + TypeScript + Vite 기반의 **한국형 1인칭 오토바이 배달 시뮬레이션** 웹 게임입니다.  
스마트폰 배달앱에서 콜을 수락하고, 오토바이를 타고 음식 픽업부터 아파트·빌라 문 앞 배달까지 직접 주행하며 완료할 수 있습니다.

## 주요 기능

- **항상 1인칭 시점 (도보 & 라이딩)**
  - 도보: 눈높이 1인칭 이동(`WASD`), 달리기(`Shift`), 점프(`Space`), 마우스 드래그 및 `←`/`→` 시선 회전
  - 오토바이: 핸들바와 윈드실드 너머 도로를 보며 코너 기울기에 맞춰 시야가 함께 기울어지는 1인칭 라이딩
- **GTA 스타일 승하차 & 코너링 전도 물리**
  - `F` 키로 자유롭게 오토바이 탑승/하차 (하차 시 사이드 스탠드 자동 거치)
  - 속도·조향각·브레이크에 따른 실시간 코너 기울기 및 타이어 접지 한계 계산
  - 코너를 과속으로 과도하게 기울이거나 기울인 상태에서 급브레이크를 밟으면 **슬립 전도(넘어짐)** 발생 → 음식 상태(%) 감소, 일어난 뒤 `F` 키로 쓰러진 오토바이를 일으켜 재탑승
- **스마트폰 배달앱 & 실시간 GPS 지도**
  - 우측 거치대 스마트폰 화면 전체에 1:1 도시 GPS 지도, 주간/야간 자동 테마(`N`), 도로 경로 안내선 표시 (`Tab`으로 확대/축소)
  - 신규 배달 콜 수락 → 상가 주황색 픽업 구역(하차 후 `E`) → 주거지 초록색 배달 구역(하차 후 `E`) → 수익 정산 및 안전배달 팁

## 로컬 실행

```bash
npm install
npm run dev
```

## GitHub Pages 배포

`.github/workflows/deploy.yml`이 포함되어 있어 `main` 브랜치에 push하면 자동 빌드 및 배포됩니다.

1. GitHub에서 `k-delivery-sim` 저장소를 생성합니다.
2. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정합니다.
3. 코드를 push하면 `https://<GitHub아이디>.github.io/k-delivery-sim/` 주소로 배포됩니다.
