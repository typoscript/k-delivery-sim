# K-Delivery Sim

Three.js + TypeScript + Vite 기반의 **한국형 1인칭 오토바이 배달 시뮬레이션** 웹 게임입니다.  
별도 설치 없이 브라우저에서 바로 스마트폰 배달앱 콜 수락, 야외 픽업대 POS 번호 입력, 오토바이 배달통 적재, 도로 주행, 공동현관 비밀번호 입력, 엘리베이터 이동, 문 앞 배달 인증 사진 촬영까지 전 과정을 체험할 수 있습니다.

## 주요 기능

- **전체 한국형 배달 워크플로우 (7단계)**
  1. **콜 수락 (`Tab` → `V`):** 스마트폰 배달앱에서 주문번호(`A-12` 등), 고객 호수(`1402호`), 공동현관 PIN이 포함된 신규 콜 수락
  2. **매장 야외 픽업대 & POS 입력 (`E`):** 매장 앞 야외 픽업대에서 `E`를 눌러 POS 키패드에 주문번호 입력 → 1인칭 왼손에 3D 음식 포장 봉투 장착 (`CARRYING_FOOD`, 음식을 손에 든 채로는 운전 불가)
  3. **오토바이 배달통 적재 (`E`):** 오토바이 뒤편 배달통에서 `E`를 누르면 뚜껑이 열리며 음식 적재 (`CARGO_LOADED`) → 이제 `F`로 탑승해 주행 가능
  4. **배달지 도착 & 배달통 꺼내기 (`F` → `E`):** 목적지 도착 후 하차하여 배달통에서 `E`로 음식 봉투 꺼내기
  5. **1층 공동현관 비밀번호 & 엘리베이터 (`E`):** 1층 유리문 앞에서 4자리 PIN 입력 시 유리문 개방 → 엘리베이터 탑승 시 2초 검은 페이드아웃 전환
  6. **모듈형 아파트 실내 복도 (`y = -500`) & 렌더링 최적화:** 지하 독립 복도 룸으로 순간이동하며 **외부 도시 맵·트래픽·오토바이 그룹을 `visible = false`로 완전 차단**해 브라우저 렌더링 부하 제거
  7. **문 앞 내려놓기 & 인증 사진 촬영 (`E` → `Space`):** 목표 호수 발매트 앞에서 `E`로 음식 내려놓기 → 스마트폰 카메라 뷰파인더 오버레이 → `Space`(또는 셔터 버튼)로 실제 3D 화면 인증샷 촬영 및 정산 팝업 표시 → 엘리베이터로 1층 바이크 앞 복귀
- **항상 1인칭 시점 + 실시간 후방 사이드미러 + 깜빡이**
  - 도보 눈높이 1인칭 이동, 오토바이 핸들바 시점 + 코너 호라이즌 롤
  - 좌/우 핸들바 사이드미러에 실시간 좌우 반전 후방 도로·AI 차량 표시
  - `Q` / `E` / `X` 깜빡이·비상등 (3D 계기판 LED, 바엔드 램프, 틱톡 사운드, 회전 후 자동 해제)
- **3D 1인칭 손 & 오토바이 거치대 스마트폰 + 물리적 소지 판정 (`Tab` / `V`)**
  - 평소에는 주머니 수납 / 도보 중 `Tab`으로 3D 오른손에 들기 / 라이딩 중 `Tab`으로 **3D 손이 주머니에서 꺼내 오토바이 거치대에 장착·분리하는 애니메이션** 재생
  - **물리적 소지 규칙:** 휴대폰을 오토바이 거치대에 꽂아둔 채 하차(`F`)하면 오토바이에 그대로 남아 도보 중 휴대폰을 사용할 수 없으며, 오토바이 근처에서 `Tab`으로 다시 챙겨야 함
  - `V` 또는 3D 휴대폰 클릭으로 중앙 확대 조작 (`V`/`Esc` 축소)
- **확장된 한국형 도시 맵 (25개 블록 · 인도 · 버스정류장 · 시내버스)**
  - 6×6 도로망(36개 교차로, 약 570m × 570m 규모)과 40동 이상의 상가·아파트·오피스텔·병원·백화점·고층 타워 배치 (픽업 매장 9곳, 주거지 배달처 12곳)
  - 보도블록 텍스처, 화강암 연석, 횡단보도 앞 노란 점자블록, 코너 볼라드가 구현된 입체 인도
  - 주요 대로변 **한국형 버스정류장 8곳**(유리 쉘터·벤치·BIT 전광판·노란 버스 정차 구역)과 **파란/초록 시내버스 6대**(LED 노선판 포함, 정류장 도착 시 비상등 점멸 후 약 3.4초 정차) + 일반 AI 차량 22대
- **코너링 기울기 전도 물리 & 3색 신호등**
  - 과속 코너링·코너 중 급브레이크 시 타이어 접지 한계 초과로 슬립 전도(배달통 음식 파손도 반영)
  - 36개 교차로 3색 신호등, 빨간불 통과 시 신호 위반 벌금(`-₩1,000`)

## 조작법

| 키 | 기능 |
| :--- | :--- |
| `F` | 오토바이 탑승 / 하차 / 쓰러진 오토바이 일으켜 탑승 *(음식 든 채 운전 불가)* |
| `E` | *(도보)* 야외 픽업 POS / 배달통 적재·꺼내기 / 공동현관 PIN / 엘리베이터 / 문 앞 내려놓기 · *(라이딩)* 우깜빡이 |
| `Tab` | *(도보)* 주머니 ↔ 3D 손 휴대폰 · *(라이딩)* 주머니 ↔ 3D 오토바이 거치대 |
| `V` / `3D 폰 클릭` | 휴대폰 확대해서 보기 / 축소 (`Esc` 축소) |
| `Space` | *(카메라 모드)* 배달 인증 사진 촬영 · *(도보)* 점프 · *(라이딩)* 급브레이크 |
| `W` `A` `S` `D` | 도보 이동 / 오토바이 가속·브레이크(저속 후진)·조향 |
| `Shift` | *(도보)* 달리기 |
| `마우스 드래그` / `←` `→` | 1인칭 시선 회전 (`R` 또는 더블클릭으로 정면 복귀) |
| `Q` / `X` | 좌깜빡이 / 비상등 |
| `L` / `N` | 헤드라이트 / 낮·밤 전환 |
| `H` / `M` | 경적 / 사운드 음소거 |
| `Backspace` | 위치 초기화 |
