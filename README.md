# K-Delivery Sim

Three.js + TypeScript + Vite 기반의 **한국형 1인칭 오토바이 배달 시뮬레이션** 웹 게임입니다.  
별도 설치 없이 브라우저에서 바로 최대 3건 동시 묶음 배달(다건 배차), 3칸 배달통 슬롯 관리, A* 도로망 내비게이션 경로 유도, 라이딩 턴바이턴 거치대 미니맵, 야외 픽업대 POS 번호 입력, 공동현관 PIN·엘리베이터 이동, 문 앞 배달 인증 사진 촬영까지 전 과정을 체험할 수 있습니다.

## 주요 기능

- **🕐 게임 시계 · 해 질 녘 조명 · 점심/저녁 피크타임 ([GameClock.ts](./src/game/GameClock.ts))**
  - **시간이 흐르는 도시:** 실제 1초 = 게임 1분(하루 24분)으로 시계가 흐르고, 상단 HUD에 근무일·게임 시각·시간대, 휴대폰 상태바에 게임 시각이 표시됩니다. 출근은 점심 피크 직전인 10:40에 시작합니다.
  - **해 질 녘·새벽 조명:** 18:30~19:30에 하늘·안개·햇빛이 서서히 어두워지며 건물 창문이 켜지고, 05:30~06:30에 다시 밝아집니다. 19:00부터 06:00까지는 밤으로 심야 할증(`+₩1,200`)이 붙고 가로등이 켜지며 헤드라이트가 자동 점등됩니다.
  - **피크타임 수요:** 점심(11:00~13:30)·저녁(17:00~20:30) 피크에는 콜이 2배 넘게 빨리 들어오고(콜 간격 10초 → 4.5초) 건당 **🔥 피크 할증 `+₩1,000`**이 붙지만 매장 조리 대기는 1.4배 길어집니다. 오후 한산(1.2배)·새벽(2배)에는 콜 간격이 길어집니다. 피크 시작은 알림·음성으로 안내하고, 할증은 콜 목록·배차 팝업·정산서·일일 명세서에 표시됩니다.
  - **소리 · 연출:** 피크 시작 시 상승 징글과 시계 배지 반짝임(끝날 때는 짧은 종료음), 비가 오기 시작하면 멀리서 천둥소리, 오늘의 목표 달성 시 팡파르에 반짝이는 효과음, 퇴근 정산 때는 하루를 마무리하는 멜로디가 나옵니다(모두 Web Audio 합성, 음원 파일 없음)
- **⏱️ 특별 주문 & ⭐ 단골 고객 ([orderFactory.ts](./src/delivery/orderFactory.ts))**
  - 한집배달 콜의 약 14%가 특별 주문입니다. **⏱️ 급한 배달**(밤에 잦음)은 제한시간 150초에 급송 할증 `+₩3,000`을 주지만 시간 안에 도착해야만 지급되고, **🍱 단체 주문**(점심·저녁 피크에 잦음)은 그 가게 메뉴 10인분이라 픽업대에서 8초 더 기다리고 제한시간 420초에 할증 `+₩2,500`을 줍니다. 콜 목록·배차 팝업에 태그로 표시됩니다
  - 특별 주문 콜은 전용 알림음·음성("급한 배달 콜이 도착했습니다")과 함께 배차 팝업 배지가 빛나고, 급한 배달은 30초 남으면 경고·음성 후 1초마다 초침 소리가 납니다
  - **🍲🍗🍱☕ 이벤트 콜 ([demandEvents.ts](./src/delivery/demandEvents.ts)):** 날씨와 시간대에 따라 들어오는 메뉴가 달라집니다(그런 메뉴가 있는 가게만, 콜 카드에 태그 표시). **비가 오면 🍲 국물 요리**(국밥·짬뽕·찌개·라멘, 음식 상태 70% 이상이면 +₩1,000), **점심 피크(11:00~13:30)엔 🍱 든든한 한 끼**(백반·정식·덮밥·도시락·돈카츠, 제한시간 안에 배달하면 +₩700), **오후 한산 시간(13:30~17:00)엔 ☕ 커피·디저트**(아메리카노·라떼·케이크·에이드, 음료 상태 80% 이상이면 +₩600), **해가 진 뒤엔 🍗 야식**(치킨·족발·피자·떡볶이, 온도 50% 이상이면 +₩800)이 더 자주 들어옵니다. 조건을 못 지키면 정산서에 이유가 표시되고, 일일 명세서에는 `🎉 이벤트 콜 할증` 항목으로 모입니다. 비가 오거나, 점심 피크가 시작되거나, 오후로 넘어가거나, 해가 질 때 알림에도 함께 안내됩니다
  - **⭐ 평판 ([reputation.ts](./src/delivery/reputation.ts)):** 최근 고객 리뷰 10개의 평균 별점과 신뢰 평점(보행자 사고 시 감점)으로 평판이 정해집니다 — 🏅 최우수(별점 4.6↑): 특별 주문 1.8배·콜 간격 -15% / 👍 우수(4.3↑): 특별 주문 1.3배 / 🙂 보통 / ⚠️ 낮음(별점 3.5 미만 또는 신뢰 평점 3 미만): 특별 주문 0.4배·콜 간격 +40%. 상단 별점 배지와 휴대폰 `💳 뱅크 → [고객 리뷰]`에 표시되고, 평판이 바뀌면 알림이 뜹니다
  - 같은 고객 주소에 2번 배달하면 그다음부터 **⭐ 단골 고객**이 되어, 음식 상태 80% 이상으로 도착하면 팁 `+₩800`을 더 줍니다(커리어에 저장). 특별 주문 할증과 단골 팁은 정산서·일일 명세서에 따로 표시됩니다
- **⭐ 한국형 고객 별점 리뷰 피드 & 단골 매장 우선 조리 우대**
  - **배달 완료 실시간 고객 리뷰 생성:** 매 배달 정산 시 음식 상태(파손/국물 쏟음)·보온/보냉 온도 유지·배달 속도·원룸/빌라 계단·우천/심야 조건·요청사항 준수 여부를 종합해 **1~5점 별점 + 생생한 한국형 리뷰 멘트 + 해시태그**(`#국물안샘`, `#보냉완벽`, `#계단감사`, `#우천감사` 등)를 생성하여 정산 팝업에 즉시 표시하고 `localStorage`에 영구 저장(최근 25건)합니다.
  - **스마트폰 `💳 뱅크` → `[⭐ 고객 리뷰]` 피드:** 평균 별점, 누적 리뷰 리스트, 단골 매장 목록을 스마트폰 배달앱에서 언제든 열람할 수 있습니다.
  - **⭐ 단골 매장 우선 조리 우대:** 같은 매장에서 **2회 이상 픽업**하면 해당 매장이 **`⭐ 단골`** 배지(콜 목록·20초 배차 팝업·수락 주문·POS 키패드 표시)를 획득하며, 피크타임 조리 대기 시 **사장님 우선 조리 우대(조리 대기 시간 대폭 단축 또는 즉시 픽업)** 혜택이 자동 발동됩니다.
- **🏆 라이더 등급(브론즈→마스터) · 5종 성능 장비 업그레이드 상점 · 커리어 영구 저장 (`localStorage`)**
  - **커리어 영구 저장 ([RiderCareer.ts](./src/delivery/RiderCareer.ts)):** 지갑 잔고·누적 배달 건수·신뢰 평점·보유 장비가 브라우저에 자동 저장되어 새로고침이나 구역 순간이동(`P`) 후에도 그대로 이어집니다.
  - **4단계 라이더 등급:** 누적 배달 실적에 따라 **🥉 브론즈(`0건+`) → 🥈 실버(`5건+`, 건당 `+₩300`) → 🥇 골드(`15건+`, 건당 `+₩600`) → 👑 마스터(`30건+`, 건당 `+₩1,000`)**로 승급하며 상단 HUD 배지 및 정산 명세서에 반영됩니다.
  - **🔧 번개 오토바이 센터 5종 성능 업그레이드:**
    - `🔥 프리미엄 보온·보냉 배달통 (₩40,000)`: 음식 온도 하락 `-40%`
    - `🛞 고성능 쇼바 & 빗길 타이어 (₩50,000)`: 방지턱·국물 출렁임 파손 `-40%`, 코너/빗길 접지력 `+14%`
    - `⚡ 고속 무선충전 거치대 (₩30,000)`: 오토바이 거치대 폰 무선충전 속도 `2배`
    - `⛽ 대용량 탱크 · 에코 셀 (₩35,000)`: 연료·EV 배터리 소모 `-25%`
    - `🏍️ ECU 출력 튜닝 (₩60,000)`: 가속력 `+14%`, 최고속도 `+8%`
    - `🧥 라이더 우비 세트 (₩18,000)`: 비·눈을 맞아도 체력 회복이 느려지지 않음(없으면 비·눈 속 실외에서 체력 회복 55%), 헬멧 바이저 물방울 `-65%`
    - `🧤 방한 장갑 · 넥워머 (₩15,000)`: 기온 2°C 이하 추위에도 체력 회복이 느려지지 않음(없으면 추위 속 실외에서 체력 회복 55%) — 날씨 앱이 비 예보·추위를 보고 장비를 챙기라고 알려줍니다
- **🌙 야간 주행 실감 강화 (조향 연동 3D 헤드라이트 빔 · 수원 야경 · 심야 할증 `+₩1,200`)**
  - **조향 연동 3D 헤드라이트 `SpotLight` & 볼류메트릭 광선 콘:** 야간(`N`) 또는 우천 시 헤드라이트(`L`)를 켜면 핸들 조향 방향을 따라 코너 앞 도로·차량·보행자를 실제로 비추는 강력한 3D 광원 빔과 안개 광선 콘이 생성되며, 기종별 램프 색온도(PCX 제논 화이트 / 슈퍼커브 웜 할로겐 / EV-PRO 아이스 블루)가 다르게 표현됩니다.
  - **후방 브레이크등 붉은 발광 & 수원 야경:** 제동 시 후방 아스팔트와 사이드미러에 붉은 브레이크등 반사광이 퍼지며, 야간 모드 전환 시 주변 건물 창문 불빛(`emissiveMap`)과 교차로 가로등 황금빛 노면 조명 풀이 일제히 점등됩니다.
  - **🌙 심야 할증 (`+₩1,200`):** 야간 모드 생성 콜에 **`🌙 심야 +₩1,200`** 할증이 자동 부여되며 우천 할증(`+₩1,500`)과 중복 적용됩니다.
- **🏍️ 배달 오토바이 3종 기종 전환 & 커스텀 도색 (`🔧 번개 오토바이 센터`)**
  - 정비소(`🔧 번개 오토바이 센터`)에서 차량 수리 외에도 **3종 기종 전환** 및 **6종 커스텀 바디/배달통 도색**을 지원하며 선택한 기종·컬러가 `localStorage`에 자동 저장되어 새로고침·구역 이동 후에도 그대로 유지됩니다:
    - **🛵 배달 PCX 125 (기본):** 밸런스형(최고 `81km/h`, 안정적 코너링 그립 `+6%`, 스모크 윈드스크린)
    - **🏍️ 클래식 슈퍼커브 110 (`₩80,000`):** 초고연비(연료 소모 `-48%`) · 민첩한 골목 조향(`+18%`) · 레트로 원형 헤드라이트·가죽 시트·단기통 엔진음
    - **⚡ 고출력 전기스쿠터 EV-PRO (`₩150,000`):** 초반 급가속(`+28%`) · 최고 `86km/h` · 머플러 제거·시안 LED 라이트바·초정숙 전기모터 인버터 사운드 · EV 전용 디지털 계기판
  - **6종 커스텀 도색:** 펄 화이트 · 배민 민트 · 레이싱 레드 · 레트로 크림 · 매트 블랙 · 수원 블루 (기본 펄 화이트 외 각 `₩15,000`, 보유 시 무료 재적용)
- **수원 4개 구역 시그니처 3D 랜드마크 디테일 ([SuwonLandmarks.ts](./src/world/SuwonLandmarks.ts))**
  - 실제 OSM 건물·도로 좌표 위에 각 구역의 상징 건축물·조형물을 저폴리곤 3D로 구현하고 야간 조명·스마트폰 GPS 랜드마크 핀과 연동:

- **24시 한국 편의점 (`🏪 K-24 편의점`) & 스마트폰 배터리 · 오토바이 거치대 무선충전**

  4. **배달지 도착 & 해당 슬롯 꺼내기 (`F` → `E` → `1`~`3`):** 목적지 도착 후 하차하여 배달통에서 해당 주문번호 슬롯의 음식 꺼내기
  5. **1층 공동현관 비밀번호 & 엘리베이터 (`E`):** 1층 유리문 앞에서 4자리 PIN 입력 시 유리문 개방 → 엘리베이터 탑승 시 2초 검은 페이드아웃 전환
  6. **모듈형 아파트 실내 복도 (`y = -500`) & 렌더링 최적화:** 지하 독립 복도 룸으로 순간이동하며 **외부 도시 맵·내비 라인·트래픽·오토바이 그룹을 `visible = false`로 완전 차단**
  7. **문 앞 내려놓기 & 인증 사진 촬영 (`E` → `Space`):** 목표 호수 발매트 앞에서 `E`로 음식 내려놓기 → 카메라 뷰파인더 → `Space`로 인증샷 촬영 및 정산 → 엘리베이터 복귀 후 다음 묶음 동선 자동 안내
- **항상 1인칭 시점 + 실시간 후방 사이드미러 + 깜빡이**
  - 도보 눈높이 1인칭 이동, 오토바이 핸들바 시점 + 코너 호라이즌 롤
  - 좌/우 핸들바 사이드미러에 실시간 좌우 반전 후방 도로·AI 차량 표시
  - `Q` / `E` / `X` 깜빡이·비상등 (3D 계기판 LED, 바엔드 램프, 틱톡 사운드, 회전 후 자동 해제)
- **3D 1인칭 손 & 오토바이 거치대 스마트폰 + 물리적 소지 판정 (`Tab` / `V`)**
  - 평소에는 주머니 수납 / 도보 중 `Tab`으로 3D 오른손에 들기 / 라이딩 중 `Tab`으로 **3D 손이 주머니에서 꺼내 오토바이 거치대에 장착·분리하는 애니메이션** 재생
  - **물리적 소지 규칙:** 휴대폰을 오토바이 거치대에 꽂아둔 채 하차(`F`)하면 도보 중 앱 확대(`V`), 자동 주문번호/PIN 메모 조회, 엘리베이터 인증 촬영 진입이 차단되며 오토바이 근처에서 `Tab`으로 챙겨야 함
- **한국형 거리 · 버스정류장 · 시내버스 · 교통 AI**
  - 보도블록 텍스처, 화강암 연석, 점자블록, 코너 볼라드, 실측 버스정류장 228곳, 신호 교차로 470곳의 3색 신호등
  - **저폴리곤 차량 & 선단 12m 레이캐스트 교통 AI (`TrafficSystem`):** 베벨 가공 저폴리곤 세단·**서울 택시(주황/은색, 지붕 캡 점등 & 빈차등)**·시내버스 24대가 플레이어 주변 165m 안에서 순환하며, 신호등 RED/YELLOW 정지선 3m 전 감속 정차(`DECELERATING → STOPPED`), 전방 12m 레이캐스트 5m 앞차 추돌 방지, 플레이어 끼어들기 시 급정거 및 1회 Web Audio 경적음 송출 (실내 복도 진입 시 `visible = false` 완전 차단)
  - **교통 규칙 엔진 (`TrafficRules`):** 정지선(교차로 중심 7m 전)까지 부드러운 제동 곡선으로 정차하고, 다음 구간을 미리 선택해 짧은 진입로에서도 신호를 지킴(황색 딜레마 구간·이미 진입한 차량은 통과). 비스듬히 만나는 실측 OSM 교차로도 교차로별 기준 도로로 2개 신호 현시를 나눠 동시 녹색 방지. 일반 차량·경찰 순찰차·경쟁 라이더·플레이어 신호위반 판정이 같은 규칙 공유
  - **차체 정렬 충돌 판정 & 부드러운 회전:** 차체 방향대로 회전한 직사각형 충돌 판정으로 차 앞뒤·모서리·버스 오버행 관통 방지, 교차로 회전·막다른 길 유턴 시 차선 오프셋 순간이동 대신 주행 거리 기반(3.5m) 보간. 비신호 교차로에서 서로 막힌 차량은 2초 후 우선순위로 양보해 교착 해소, 재스폰 시 차량 겹침 방지
  - **인도 웨이포인트 & 횡단보도 신호 연동 보행자 AI + 인도 주행 회피/사고 페널티 (`PedestrianGraph` & `PedestrianManager`):**
    - 도로망 전체의 인도 중심선·노란 점자블록 횡단보도 그래프 위에서 `WALKING`(1.0~1.3 m/s) → `WAITING_CROSSWALK`(점자블록 대기) → `CROSSING`(교차로 3색 신호등 연동, 점멸 시 1.5배 달리기) FSM 이동, 80m 밖 자동 컬링 및 복도(`y = -500`) 진입 시 틱 일시정지
    - **인도 양보 & 우회:** 앞을 막은 플레이어·주차된 오토바이 앞에서 1.6초 기다린 뒤 옆으로 비켜 돌아감(뒤쪽 장애물에는 멈추지 않음). 횡단 중 넘어진 보행자는 일어나 신호에 맞춰 횡단을 마저 끝냄
    - **차량의 보행자 양보:** AI 차량이 횡단보도를 건너거나 도로에 쓰러진 보행자를 감지해 차선 앞에서 정차
    - **신호 없는 교차로 무단횡단 방지:** 보행자는 교차로·막다른 길·신호등에서만 길을 건너고(블록 중간에서는 건너지 않음), 신호 없는 곳에서는 다가오는 차가 지나갈 때까지 기다렸다가 건넙니다(25초 넘게 틈이 없으면 인도로 계속 걸어감). 앞을 막은 차량 쪽으로는 걸어 들어가지 않습니다
    - **차량 충돌 판정:** 차량·버스 충돌 영역은 실제 차체 방향대로 회전한 직사각형이고, AI 차량은 차선 앞(앞 범퍼 모서리 포함)의 오토바이·도보 플레이어·세워 둔 오토바이를 감지해 멈추고, 차선에 서 있는 오토바이 뒤에서 3초 기다린 뒤 마주 오는 차가 없으면 왼쪽으로 비켜 천천히 지나갑니다. 차가 밀고 들어와 겹치면 오토바이·플레이어·보행자를 차체 밖으로 밀어냅니다([vehicleBodies.ts](./src/world/vehicleBodies.ts))
    - **보행자 근접 경계 반응:** 오토바이가 보행자 쪽으로 **걷는 속도보다 빠르게(1.2m/s 이상)** 다가오며 전방·측방 **3.5m 이내**에 들어오면 걸음을 멈추고 움츠림·방어 회피 스텝(`STARTLED`) 및 놀람 효과음 재생. 정차·서행 중인 오토바이에는 놀라지 않고(대신 인도 양보 후 우회), 한 번 놀란 뒤 4초간은 1.6m 이내로 돌진할 때만 다시 놀람
    - **보행자 접촉 사고 판정(AABB + BoundingSphere):** **시속 5km/h 이상 주행 중** 보행자와 직접 접촉 시에만 사고로 판정(정차·주차/하차 중 오작동 방지) → 보행자 넘어짐 애니메이션(`FALLEN`), 오토바이 즉시 슬립 전도(배달통 음식 파손 `-55%`), 상단 **`🚨 보행자 접촉 사고 발생!`** 경고 배너 출력, **과태료·합의금 -₩50,000 즉시 차감** 및 **배달 기사 신뢰 평점 -1.0점** 감점 처리

## 수원 통합 오픈월드 (기본 맵)

인계동·행궁동·수원역·광교 4개 구역과 그 사이 지역 전체(약 6.2km × 4.25km, 도로 476km · 건물 2만여 동)가 **하나의 끊김 없는 도시**입니다. 오픈월드 게임처럼 맵을 200m 청크로 나눠 **플레이어 주변 5×5 청크(1km × 1km)만 불러오고**, 멀어진 청크는 메모리에서 해제합니다.

- **가로수 · 가로등 · 전봇대:** 큰길 양쪽 보도에는 12m 간격으로 가로수가(크기·잎 색이 조금씩 다름), 그 사이 30m 간격으로 양쪽 번갈아 도로 위로 팔을 뻗은 가로등이 서서 밤에는 등이 켜지고 도로에 빛이 번지며(조명 계산 없는 텍스처 방식, 낮에는 빛 웅덩이를 그리지 않음), 골목에는 한쪽으로 28m 간격의 전봇대와 전선·변압기가 섭니다. 도로 정보로 위치를 한 번 정해 두고, 플레이어 주변 청크에서만 청크당 한 덩어리(드로우콜 1번)로 만들었다가 멀어지면 정리합니다
- **도로 디테일:** 큰길에는 양쪽 흰색 차선 경계선과 보도 경계석(연석)이, 편도 2차로 이상 넓은 길에는 흰색 점선 차선이, 가장 넓은 간선도로(14.5m)에는 바깥 차로에 파란 버스전용차로 선과 `버스전용` 노면 글씨가 그려지고, 골목 교차로 앞에는 `천천히`, 초등학교·유치원·어린이집 근처에는 `어린이보호구역` 노면 글씨가 있으며, 신호 교차로에서는 횡단보도 앞 진입 차로에 정지선이 있습니다(노란 중앙선·흰 차선·연석은 청크마다 한 덩어리로, 정지선은 횡단보도 줄무늬와 같은 인스턴싱으로 그려 드로우콜 증가 없음)
- **아파트 단지 입구:** 아파트 공동현관 한쪽에는 단지 안에 주차된 차 2~4대가, 다른 쪽에는 경비실과 빨강·흰 줄무늬 차단기가 있습니다(도로나 다른 건물과 겹치는 자리는 건너뛰고, 단지마다 한 덩어리 메시로 그림). 주차된 차와 경비실은 부딪히는 충돌체입니다
- **건물 외관 · 옥상:** 같은 종류의 건물도 건물마다 외벽 색조가 조금씩 다르고(베이지·회색·붉은 벽돌·푸른빛 등), 36m 이하 건물에는 옥상 난간과 계단실·물탱크·에어컨 실외기가 올라갑니다(도로에서 보이지 않는 고층 옥상은 생략, 기존 재질에 합쳐 드로우콜 증가 없음)
- **1층 상가 거리:** 도로에 맞닿은 저층 건물(상가·빌라·작은 사무실·식당)의 도로 쪽 1층에 약 6m 간격으로 유리 상가와 색색의 간판이 붙어 한국 상가 거리처럼 보입니다(아파트 고층동·학교·역 같은 큰 건물 제외). 청크마다 유리·간판을 한 덩어리(드로우콜 1번)로 합쳐 그리고, 해가 지면 간판이 제 색으로 은은하게 빛나고 유리창에는 가게 안 따뜻한 불빛이 켜집니다(셰이더에서 정점 색으로 발광, 해 질 녘에 서서히), 배달 가게는 픽업대 뒤에 가게 이름 큰 간판·차양·유리 매장 전면이 있어 멀리서도 찾기 쉽습니다
- **`[P]` 구역 바로 이동:** 새로고침 없이 그 구역으로 순간이동하며 진행 중인 배달·적재 음식·지갑이 그대로 유지됩니다. 상단 배지와 휴대폰 지역명은 현재 위치한 구역을 따라갑니다.
- **도시 어디서나 배달 콜 (가게 약 340곳 · 배달지 약 1,440곳):** 4개 구역에서 직접 다듬은 가게·배달지에 더해, 그 사이 지역 전체에도 OSM 실제 음식점(이름·업종별 이모지·메뉴)과 동네 가게, 아파트 동·빌라(계단 할증)·오피스텔 배달지가 차도 옆 인도에 생성되어 있습니다. 픽업 카운터·공동현관 소품은 플레이어 주변에서만 만들고 멀어지면 해제합니다.
- **현지 배달 콜:** 주문은 라이더 주변 900m 안의 가게와, 그 가게에서 1.1km 안의 고객으로만 만들어지고(도시 반대편 5km 콜 없음), 후보가 충분하면 가게 바로 옆(120m 미만) 고객은 건너뜁니다.
- **도시 전체 시스템:** 4개 구역의 가게·배달지·주유소·정비소·편의점·랜드마크가 모두 실제 위치에 있고, 교통 AI·보행자·경찰·경쟁 라이더는 플레이어 주변에서 순환하며, 신호등·가로등·버스정류장(228곳) 등 소품은 가까운 것만 표시합니다.
- **빠른 첫 화면 & 나눠 받기:** 주소를 열면 로딩 화면이 바로 뜨고, 게임 코드(약 140kB)·three.js(약 130kB)·지도 데이터(약 220kB, gzip 기준)를 따로 동시에 내려받습니다. 각각 따로 캐시되므로 게임 코드가 바뀌어도 three.js와 지도는 다시 받지 않고, 예전 구역별 지도(약 100kB)는 `?map=legacy`일 때만 받습니다.
- **발열·배터리 절약:** 게임 루프는 60fps 상한(120Hz 화면에서도 60fps), 휴대폰 지도는 초당 10회 갱신(지도를 드래그·확대하는 동안에는 즉시 갱신)
- **절전 모드 (설정 `O`, 기본 켜짐):** 4초 이상 조작·이동이 없거나, 메뉴를 열었거나, 휴대폰을 확대해 보고 서 있을 때는 30fps로 낮춰 발열·배터리 소모를 줄이고, 키·마우스를 조작하거나 움직이면 즉시 60fps로 돌아갑니다(배달 사진 촬영 중에는 항상 60fps).
- **자동 해상도 & 그림자 품질 (설정 `O`):** GPU가 한 프레임을 그리는 실제 시간을 재서, 60fps를 못 맞추면 렌더 해상도를 단계적으로 낮추고 여유가 생기면 다시 올립니다(설정에서 끌 수 있음). 그래픽 품질별로 해상도 범위와 그림자가 달라집니다 — 높음: 해상도 1~2배 · 그림자 2048px 2프레임마다 갱신 · 맵 디테일 전부 / 보통: 0.85~1.35배 · 1024px 3프레임마다 · 옥상 구조물(계단실·물탱크·실외기)과 골목 전봇대·전선 생략(주변 청크 삼각형 약 30%, 가로 소품 약 30% 감소) / 낮음: 0.7~1배 · 그림자 끔 · 옥상·1층 상가 유리·간판·노면 글씨를 빼고 가로수·전봇대·가로등은 아예 만들지 않음(주변 청크 삼각형 약 70% 감소, 차선·연석은 유지). 품질을 바꾸면 새로고침 없이 바로 적용되고, 그림자는 플레이어를 따라가며 떨림 없이 고정됩니다.
- **보이는 곳만 그리는 도시 전역 소품:** 도시 전체의 신호등(940곳)·가로등·공원 나무·횡단보도 줄무늬는 InstancedMesh 하나씩이라 예전엔 먼 것까지 매 프레임 다 그렸는데, 이제 플레이어 주변 200~320m 안의 것만 남기고 40m 움직일 때마다 다시 고릅니다(`NearbyInstances`). 같은 장면의 화면 삼각형이 약 34.7만 → 4.3만 개(-87%)로 줄었습니다. 1인칭으로 늘 화면에 있는 내 오토바이도 움직이지 않는 부품을 재질별로 합쳐 보이는 메시가 56 → 38개로 줄었습니다(바퀴·핸들·킥스탠드·기종별 트림·배달통·조명·미러는 그대로 따로 움직임). 가까운 보행자도 몸통·머리·가방을 하나로, 팔다리는 관절마다 하나로 합쳐(정점 색) 한 명당 드로우콜이 12~14 → 5개로 줄었습니다(걷는 동작·군중 움직임은 그대로). 가게 픽업대·공동현관 소품도 색만 다른 불투명 부품(카운터·기둥·문틀·차양)을 정점 색 메시 하나로 합쳐 소품당 1~2개씩 줄였고, 이제는 청크 하나에 있는 픽업대·공동현관을 한꺼번에 만들어 그 청크 전체의 부품·유리·화면·PIN 패드를 재질별로 합칩니다(청크 단위로 함께 생기고 해제됨). 출발 지점 장면 메시가 909 → 887개로 줄었습니다(간판·움직이는 문·픽업 봉투는 그대로)
- **최악 조건 벤치마크 (`?bench=suite`):** 인계동·수원역(최고 밀도)·광교 도보, 수원역 주행(정지·이동), 밤, 비, 밤+비 주행, 눈(쌓인 눈·우산 포함) 도보·밤+눈 주행, 보통·낮음 맵 디테일까지 12개 장면을 자동으로 돌며 FPS·CPU·GPU·드로우콜을 측정해 F9 화면과 콘솔에 표로 보여줍니다(콘솔 `__benchSuite()`). 내 컴퓨터에서 얼마나 여유가 있는지 확인할 때 쓰세요. 결과는 저장된 기준값([benchBaseline.ts](./src/game/perf/benchBaseline.ts), 장면별 드로우콜·삼각형 — 기계와 상관없이 같은 빌드면 같음)과 비교해 장면마다 `기준 대비 +N%`를 보여 주고, 드로우콜 25% 또는 삼각형 30% 넘게 늘어난 장면은 `⚠️`와 콘솔 경고로 표시합니다(교통·보행자 배치 때문에 실행마다 ±15% 정도는 흔들림). 의도한 변경 뒤에는 벤치마크를 돌리고 콘솔 `__benchBaseline()`이 내놓는 값(이번 세션 실행 평균)으로 기준값을 갱신합니다.
