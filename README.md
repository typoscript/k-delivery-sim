# K-Delivery Sim

Three.js + TypeScript + Vite 기반의 **한국형 1인칭 오토바이 배달 시뮬레이션** 웹 게임입니다.  
별도 설치 없이 브라우저에서 바로 스마트폰 배달앱 콜 수락, 음식 픽업, 도로 주행, 주거지 배달까지 체험할 수 있습니다.

### 🎮 지금 바로 플레이하기
👉 **https://typoscript.github.io/k-delivery-sim/**

## 주요 기능

- **항상 1인칭 시점 (도보 & 라이딩) + 실시간 후방 사이드미러**
  - **도보:** 눈높이 1인칭 이동(`WASD`), 달리기(`Shift`), 점프(`Space`), 마우스 드래그 및 `←`/`→` 시선 회전
  - **오토바이 라이딩:** 헬멧 1인칭 시점으로 핸들바·윈드실드 너머 도로를 보며, 코너 기울기에 맞춰 시야도 함께 기울어집니다.
  - **실시간 좌/우 사이드미러:** 핸들바 양옆 사이드미러에 실제 후방 도로와 뒤따라오는 AI 차량이 실시간 좌우 반전 렌더링으로 표시됩니다.
  - **깜빡이 & 비상등 (`Q` / `E` / `X`):** 1인칭 핸들바 계기판 LED, 핸들 끝단 및 전/후면 방향지시등, 릴레이 틱톡 사운드와 **회전 완료 후 자동 해제** 지원
- **GTA 스타일 오토바이 승하차 & 코너링 전도 물리**
  - `F` 키로 자유롭게 배달 스쿠터 탑승/하차 (하차 시 사이드 스탠드 자동 거치)
  - 속도·조향각·브레이크 입력에 따른 실시간 2차 기울기(Lean) 물리 및 타이어 접지 한계 계산
  - 코너를 과속으로 과도하게 기울이거나 기울인 상태에서 급브레이크를 밟으면 타이어 스키드 경고 후 **슬립 전도(넘어짐)** 발생
  - 전도 시 배달 중인 음식 상태(%)가 감소하며, 기상 후 `F` 키로 쓰러진 오토바이를 일으켜 다시 탑승 가능
- **3D 1인칭 손 & 오토바이 거치대 스마트폰 + 확대 보기 (`Tab` / `V`)**
  - 평소에는 휴대폰이 **주머니**에 들어가 있어 화면 우측을 가리지 않고 깔끔한 1인칭 시야를 유지합니다.
  - **도보 중 `Tab`:** 주머니에서 휴대폰을 꺼내 **1인칭 3D 손에 들고** 실제 입체 원근감으로 실시간 GPS 지도와 배달 상태를 확인합니다. (추후 문 앞 배달 사진 촬영용으로 확장 가능)
  - **오토바이 탑승 중 `Tab`:** 주머니의 휴대폰을 **3D 오토바이 핸들바 거치대에 장착**하여 핸들바 위에서 실시간 GPS 내비게이션을 보며 주행합니다.
  - **확대해서 보기 (`V` 또는 3D 휴대폰 클릭):** 손에 들거나 거치대에 놓인 휴대폰을 화면 중앙으로 확대해 콜 수락, 지도 줌/추적 등 세부 조작을 편하게 할 수 있습니다. (`V`/`Esc`로 축소)
  - 스마트폰 지도에는 내 위치, 내 오토바이 위치, 배달 경로, 상가/주거지 정보만 표시됩니다 (다른 AI 차량 위치 미표시).
  - **배달 루프:** 신규 콜 수락 → 상가 주황색 픽업 구역(하차 후 `E`) → 아파트/빌라 초록색 배달 구역(하차 후 `E`) → 배달비 정산 및 안전배달 팁(`+₩500`)
- **AI 교통 차량 & 3색 교차로 신호등**
  - 16개 교차로 전체에 한국형 3색(빨강/노랑/초록) 수평 신호등과 실시간 신호 주기 적용
  - 세단·택시·밴 등 AI 차량이 우측 통행 차선을 따라 주행하며 신호 정지, 교차로 회전, 앞차 및 플레이어 회피, 야간 헤드라이트/브레이크등 점등 수행
  - 빨간불에 교차로를 통과하면 **신호 위반 경고 및 벌금(`-₩1,000`)**, 주행 차량과 고속 충돌 시 전도 발생
- **Web Audio 프로시저럴 사운드**
  - 125cc CVT 스쿠터 엔진음, 타이어 스키드 경고음, 충돌음, 경적(`H`), 깜빡이 릴레이, 콜 수락·픽업·배달 완료 효과음

## 조작법

| 키 | 기능 |
| :--- | :--- |
| `F` | 오토바이 탑승 / 하차 / 쓰러진 오토바이 일으켜 탑승 |
| `E` | *(도보)* 음식 픽업 / 문 앞 배달 완료 · *(라이딩)* 우깜빡이 |
| `W` `A` `S` `D` | 도보 이동 / 오토바이 가속·브레이크(저속 후진)·조향 |
| `Shift` / `Space` | *(도보)* 달리기 / 점프 · *(라이딩)* 급브레이크 |
| `마우스 드래그` / `←` `→` | 1인칭 시선 회전 (`R` 또는 더블클릭으로 정면 복귀) |
| `Tab` | *(도보)* 주머니에서 3D 손으로 휴대폰 꺼내기/넣기 · *(라이딩)* 3D 오토바이 거치대에 장착/분리 |
| `V` / `3D 폰 클릭` | 휴대폰 확대해서 보기 / 축소 (`Esc`로 축소 가능) |
| `Q` / `X` | 좌깜빡이 / 비상등 |
| `L` / `N` | 헤드라이트 / 낮·밤 전환 |
| `H` / `M` | 경적 / 사운드 음소거 |
| `Backspace` | 캐릭터 및 오토바이 위치 초기화 |
