# K-Delivery Sim

Three.js + TypeScript + Vite 기반의 **한국형 1인칭 오토바이 배달 시뮬레이션** 웹 게임입니다.  
별도 설치 없이 브라우저에서 바로 최대 3건 동시 묶음 배달(다건 배차), 3칸 배달통 슬롯 관리, A* 도로망 내비게이션 경로 유도, 라이딩 턴바이턴 거치대 미니맵, 야외 픽업대 POS 번호 입력, 공동현관 PIN·엘리베이터 이동, 문 앞 배달 인증 사진 촬영까지 전 과정을 체험할 수 있습니다.

### 🎮 지금 바로 플레이하기
👉 **https://typoscript.github.io/k-delivery-sim/**

## 주요 기능

- **배민커넥트 스타일 일일 정산 명세서 & 일일 배달 미션 대시보드**
  - 스마트폰 배달앱 상단에 **`[콜 목록]`**, **`[내비]`**, **`[수익]`** 3단 탭 네비게이션 구성
  - **`[수익]` 탭**에서 오늘의 배달 내역을 영수증 형태로 출력: 기본 배달료 합계, 거리 할증, 우천/기상 할증, 안전 팁·미션 보너스, 신호위반/인도사고 과태료 차감, 음식 파손 페널티 차감, 유류비/수리비, **최종 실수령액(Net Earnings)**
  - **일일 배달 미션 위젯:** `"오늘 3건 배달 완료하기 (현재 X/3)"` 실시간 게이지 바 표시, 3건 달성 시 **`+₩5,000 보너스 지급!`** 축하 팝업·팡파르 재생 및 지갑 잔고 즉시 추가
- **피크타임 매장 조리 지연 대기(Cooking Delay) & 픽업대 트레이 수령**
  - 주문이 몰리는 식당 야외 POS에서 주문번호 입력 시 즉시 나오지 않고 **5~10초 랜덤 조리 대기(`cooking_wait`)** 상태로 진입
  - 상단 HUD 및 거치대/손 3D 스마트폰 화면에 **노란색 조리 대기 카운트다운 게이지**가 표시되며, 대기 중에도 조작이 잠기지 않아 오토바이 탑승·이동·스마트폰 조작이 자유롭게 가능
  - 조리 완료 시 `"음식이 준비되었습니다!"` 딩동 알림음과 함께 야외 픽업대 트레이에 **3D 포장 봉투가 스폰**되며, 다시 `E` 키를 눌러야 왼손에 음식 봉투(`CARRYING_FOOD`)를 쥐게 됨
- **고객 요청사항 3종 분기 & 한국형 아파트 공동현관 PIN 다변화**
  - 모든 콜에 **`PHOTO_DOOR`(📸 문 앞 사진)**, **`KNOCK_DOOR`(✊ 노크 후 문 앞)**, **`MEET_FACE`(🙋 직접 대면 수령)** 요청사항이 부여됨
  - **`PHOTO_DOOR`:** 발매트에 `E`로 내려놓고 카메라 뷰파인더 중앙 60% 화각 내에 **호수 팻말 + 음식 봉투**를 모두 담아 `Space` 촬영 시 배달 완료 승인 (누락/잘림 시 경고 팝업 & 재촬영 유도)
  - **`KNOCK_DOOR`:** 문 앞에서 `E` 입력 시 현관문 노크음("똑똑똑") 재생 + 발매트 자동 배치 → 3초 후 완료
  - **`MEET_FACE`:** 현관문 옆 인터폰 벨(`E`) → "딩동! 누구세요? 배달이요!" 효과음 → 현관문이 부드럽게 **70°**로 열리며 **3D 저폴리곤 고객 NPC**가 손을 내밀어 음식을 수령 후 완료
  - **공동현관 PIN 다변화:** 단순 4자리 외에 `종모양(🔔) + 1234`, `열쇠(🔑) + 5678 + 통화(📞)`, `# + 3920 + *` 등 한국 아파트 출입 패턴을 스마트폰 상단 강조 툴팁과 도어락 특수키 패드로 지원
- **한집배달 vs 알뜰 묶음 배달 선택지 & 20초 카운트다운 콜 카드 UI**
  - `OrderDispatchManager` 상태 머신이 **🚀 한집배달(`SINGLE`: 기본 ₩4,500 + 거리 할증 · 제한시간 300초 · 단건 직행)**과 **🛵 알뜰배달(`ALTTLE_BUNDLE`: 기본 ₩2,800 × 2건 · 제한시간 500초 · 탑박스 2슬롯 분할 순차 배달)** 신규 콜을 자동 배차
  - 배민커넥트 스타일 Web Audio API 비프 알림음·진동 연출과 함께 스마트폰 화면 중앙에 **20초 원형 프로그레스 바 콜 카드** 팝업
  - 20초 내 `Tab` 또는 `V` 키로 즉시 수락 가능하며, 미응답(시간 초과) 또는 거절 시 자동 취소 후 **10초 쿨다운**을 거쳐 신규 콜 재발송
- **오토바이 연료 · 셀프 주유소 · 차량 파손 정비 & 일일 종합 정산 대시보드**
  - 주행 시 실시간 연료 소모, **3D 핸들바 계기판 디지털 연료 게이지 & 연료 10% 이하 적색 경고등 점멸 + 경고음**, 연료 고갈 시 가속 불가 전환
  - 메인 대로변 **⛽ K-오일 셀프주유소**에 오토바이를 세우고 도보 `E` 키로 셀프 주유(진행도 바 & Web Audio 결제 완료음 `"결제가 완료되었습니다"`)
  - 슬립 전도 누적 시 **차량 파손 단계(1~3단계)** 적용(사이드미러 틀어짐·흔들림 및 단계당 가속력 `-10%` 저하) → **🔧 번개 오토바이 센터**에서 수리비 결제 후 100% 복구
  - 스마트폰 앱 **`[수익/지출]` 탭** 및 **일일 종합 정산 대시보드 모달**에서 완료 건수, 기본 배달료, 거리/우천 할증, 안전 팁, 유류비, 수리비, 신호위반 과태료, 최종 순수익을 한눈에 확인
- **우천 날씨 쉐이더 & 빗길 노면 슬립(맨홀·횡단보도) 물리 + 우천 할증**
  - `U` 키(또는 상단 날씨 배지 클릭)로 **맑음 / 흐림 / 비(Rain)** 날씨 전환 가능
  - 우천 시 전체 라이팅 톤 다운·짙은 빗안개 적용 및 카메라 주변 로컬 비 파티클(`InstancedMesh` 1 DrawCall)과 Web Audio 프로시저럴 빗소리 재생 — **실내 복도(`y = -500`) 진입 시 비 파티클·빗소리 즉시 중단/음소거**
  - 도로 아스팔트 커스텀 쉐이더로 젖은 노면의 `roughness` 저하 및 웅덩이 반사·물결 하이라이트 구현
  - 36개 교차로의 **금속 맨홀 뚜껑** 및 **횡단보도 흰색 페인트선** 위에서 우천 시 브레이크 또는 급회전하면 접지력(Grip)을 잃고 미끄러져 전도(배달통 음식 파손도 증가 및 배달팁 감액 반영)
  - 우천 모드에서 생성되는 신규 배달 콜에 **`🌧️ 우천 할증 (+₩1,500)`** 라벨 및 정산 보너스 자동 적용
- **묶음 배달(다건 배차) & 배달통 3칸 슬롯 관리**
  - 스마트폰 배달앱에서 **최대 3건 동시 배차** 가능 (`콜 대기` / `수락 목록` / `완료 체크` / `추천 동선` 4개 탭 제공)
  - 오토바이 뒤편 배달통(탑박스)에 **3칸 슬롯(슬롯 1~3)** 도입 및 후면 3구 상태 LED·내부 봉투 시각화
  - 배달통 앞에서 `E` 키를 누르면 슬롯 관리 모달이 열리며, `1`~`3` 키 또는 클릭으로 주문번호(`A-12`, `B-07` 등)와 목적지·호수·PIN·음식 상태를 확인하며 개별 적재/회수 가능 (잘못 꺼낸 음식 재적재 지원)
  - 음식을 손에 든 상태(`CARRYING_FOOD`)에서는 오토바이 탑승/운전이 차단되며, 전도 사고 시 배달통에 적재된 모든 주문의 음식 상태에 파손도가 반영됨
- **6×6 도로망 A* 내비게이션 라인 & 3D 거치대 미니맵**
  - 6×6 교차로(36개 노드) 도로망 그래프 기반 **A* 최단 경로 탐색기**와 픽업→배달 선행 조건을 반영한 **묶음 추천 동선 가이드** 자동 계산
  - 3D 도로 표면 위에 **형광 녹색 궤적 폴리라인(`Line2`) + 스크롤 화살표 리본(`CanvasTexture`)**을 최소 DrawCall(2 DrawCall, 실내 복도 진입 시 자동 오클루전)로 실시간 렌더링
  - 라이딩 중 오토바이 거치대에 휴대폰을 장착(`Tab`)하면 **진행 방향 상단(Heading-Up) 회전 미니맵 + 회전 화살표(직진/좌회전/우회전/유턴/도착) + 남은 거리(m)**를 3D 화면에 실시간 표시
- **전체 한국형 배달 워크플로우 (7단계)**
  1. **묶음 콜 수락 (`Tab` → `V`):** 스마트폰 배달앱에서 주문번호(`A-12` 등), 고객 호수(`1402호`), 공동현관 PIN이 포함된 콜을 최대 3건까지 수락
  2. **매장 야외 픽업대 & POS 입력 (`E`):** 매장 앞 야외 픽업대에서 `E`를 눌러 POS 키패드에 주문번호 입력 → 1인칭 왼손에 3D 음식 포장 봉투 장착 (`CARRYING_FOOD`)
  3. **오토바이 배달통 3칸 슬롯 적재 (`E` → `1`~`3`):** 뒤편 배달통에서 `E`로 슬롯 창을 열어 빈 칸에 적재 (`CARGO_LOADED`) → `F`로 탑승해 다음 매장 또는 배달지로 주행
  4. **배달지 도착 & 해당 슬롯 꺼내기 (`F` → `E` → `1`~`3`):** 목적지 도착 후 하차하여 배달통에서 해당 주문번호 슬롯의 음식 꺼내기
  5. **1층 공동현관 비밀번호 & 엘리베이터 (`E`):** 1층 유리문 앞에서 4자리 PIN 입력 시 유리문 개방 → 엘리베이터 탑승 시 2초 검은 페이드아웃 전환
  6. **모듈형 아파트 실내 복도 (`y = -500`) & 렌더링 최적화:** 지하 독립 복도 룸으로 순간이동하며 **외부 도시 맵·내비 라인·트래픽·오토바이 그룹을 `visible = false`로 완전 차단**
  7. **문 앞 내려놓기 & 인증 사진 촬영 (`E` → `Space`):** 목표 호수 발매트 앞에서 `E`로 음식 내려놓기 → 카메라 뷰파인더 → `Space`로 인증샷 촬영 및 정산 → 엘리베이터 복귀 후 다음 묶음 동선 자동 안내
- **항상 1인칭 시점 + 실시간 후방 사이드미러 + 깜빡이**
  - 도보 눈높이 1인칭 이동, 오토바이 핸들바 시점 + 코너 호라이즌 롤
  - 좌/우 핸들바 사이드미러에 실시간 좌우 반전 후방 도로·AI 차량 표시
  - `Q` / `E` / `X` 깜빡이·비상등 (3D 계기판 LED, 바엔드 램프, 틱톡 사운드, 회전 후 자동 해제)
- **3D 1인칭 손 & 오토바이 거치대 스마트폰 + 물리적 소지 판정 (`Tab` / `V`)**
  - 평소에는 주머니 수납 / 도보 중 `Tab`으로 3D 오른손에 들기 / 라이딩 중 `Tab`으로 **3D 손이 주머니에서 꺼내 오토바이 거치대에 장착·분리하는 애니메이션** 재생
  - **물리적 소지 규칙:** 휴대폰을 오토바이 거치대에 꽂아둔 채 하차(`F`)하면 도보 중 앱 확대(`V`), 자동 주문번호/PIN 메모 조회, 엘리베이터 인증 촬영 진입이 차단되며 오토바이 근처에서 `Tab`으로 챙겨야 함
- **확장된 한국형 도시 맵 (25개 블록 · 인도 · 버스정류장 · 시내버스)**
  - 6×6 도로망(36개 교차로, 약 570m × 570m 규모)과 40동 이상의 상가·아파트·오피스텔·병원·백화점·고층 타워 배치 (픽업 매장 9곳, 주거지 배달처 12곳)
  - 보도블록 텍스처, 화강암 연석, 점자블록, 코너 볼라드, 한국형 버스정류장 8곳, 시내버스 6대 + 일반 AI 차량 22대, 36개 교차로 3색 신호등
  - **저폴리곤 보행자(`PedestrianFactory` & `PedestrianSystem`):** 공유 `BoxGeometry` 및 재사용 머티리얼 풀 기반 한국형 남녀 일상복 보행자 36명이 인도를 순회하며 `Math.sin()` 절차적 보행/차려자세(Idle) 보간 애니메이션으로 이동 (실내 복도 진입 시 자동 오클루전)

## 조작법

| 키 | 기능 |
| :--- | :--- |
| `F` | 오토바이 탑승 / 하차 / 쓰러진 오토바이 일으켜 탑승 *(음식 든 채 운전 불가)* |
| `E` | *(도보)* 야외 픽업 POS / 배달통 3칸 슬롯 / 주유소 주유 / 정비소 수리 / 공동현관 PIN / 엘리베이터 / 문 앞 내려놓기 · *(라이딩)* 우깜빡이 |
| `1` `2` `3` | *(배달통 슬롯 모달)* 1~3번 슬롯 음식 즉시 적재 / 꺼내기 |
| `Tab` | *(도보)* 주머니 ↔ 3D 손 휴대폰 · *(라이딩)* 주머니 ↔ 3D 오토바이 거치대 (내비 모드) |
| `V` / `3D 폰 클릭` | 휴대폰 확대해서 보기 / 축소 (`Esc` 축소) |
| `Space` | *(카메라 모드)* 배달 인증 사진 촬영 · *(도보)* 점프 · *(라이딩)* 급브레이크 |
| `W` `A` `S` `D` | 도보 이동 / 오토바이 가속·브레이크(저속 후진)·조향 |
| `Shift` | *(도보)* 달리기 |
| `마우스 드래그` / `←` `→` | 1인칭 시선 회전 (`R` 또는 더블클릭으로 정면 복귀) |
| `Q` / `X` | 좌깜빡이 / 비상등 |
| `U` | 날씨 전환 (`맑음` → `흐림` → `비 / 우천 할증 +₩1,500`) |
| `L` / `N` | 헤드라이트 / 낮·밤 전환 |
